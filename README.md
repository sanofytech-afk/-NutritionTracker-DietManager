# 🥗 Nutrition Tracker & Diet Manager

A Python-based application designed to help users track their daily food intake, monitor nutritional information, and manage their dietary goals.

## 📌 Project Overview

The Nutrition Tracker & Diet Manager aims to provide a simple way to record meals, analyse nutritional intake, and monitor daily energy requirements through a user-friendly graphical interface.

This project is being developed as part of our Python programming coursework.

## ✨ Planned Features

- **User-Friendly Interface:** A desktop GUI built using Python's Tkinter.
- **Food & Meal Logging:** Record meals and track daily food intake.
- **Nutrition Tracking:** Organise food and nutritional information.
- **BMI Calculator:** Calculate Body Mass Index (BMI).
- **Daily Calorie Estimation:** Estimate daily energy requirements using established formulas.
- **Data Storage:** Store food records and meal logs using SQLite.
- **Progress Summaries:** View summaries of recorded dietary intake.

*Features are planned and will be updated as development progresses.*

## 🛠️ Technology Stack

- **Language:** Python
- **GUI:** Tkinter
- **Database:** SQLite
- **Data Visualisation:** Matplotlib
